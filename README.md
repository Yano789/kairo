# Kairo: Your Campus Life. Organized.

[![Comp-Struc-and-Info-Sys-Posters.png](https://i.postimg.cc/W3wh9D9R/Comp-Struc-and-Info-Sys-Posters.png)](https://postimg.cc/S2jSRKFV)

Kairo is an innovative all-in-one student life management application designed to centralize and simplify campus information and scheduling for SUTD students.

## Features

- **Seamless Authentication**: Single sign-on with university credentials
- **Discovery Page**: Curated feed of campus and fifth-row events with filtering
- **Calendar View**: Monthly overview with color-coded activity indicators
- **Schedule Page**: Detailed weekly timetable with customizable events
- **Kai Chatbot**: AI assistant for natural language schedule management
- **Profile Page**: Personalization options and student information storage

## Installation

1. Clone this repository:
   ```
   git clone https://github.com/Yano789/kairo.git
   ```
2. Open the project in Android Studio

3. Build and run on your Android device or emulator (API 21+)


## Technologies Used
- Frontend: Android (Java, XML)

- Libraries:

  - Material CalendarView

  - ThreeTenABP

  - Guava

  - Retrofit

- APIs: OpenRouter API (DeepSeek)
